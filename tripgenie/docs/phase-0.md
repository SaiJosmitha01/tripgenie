# Phase 0 Foundation

Phase 0 establishes the TripGenie enterprise platform foundation only.

Included:

- Monorepo directory layout.
- Java 21 Spring Boot 3 Maven multi-module backend.
- Modular-monolith-first service boundaries.
- React and TypeScript frontend scaffold.
- Docker Compose dependencies for PostgreSQL, Redis, and Kafka.
- OpenAPI, Actuator, logging, profiles, and Flyway baseline structure.
- CI workflow for build, unit test, and Docker Compose validation.

Deferred:

- Authentication behavior.
- AI planning behavior.
- Business domain workflows.
- Production Kubernetes sizing, ingress, secrets, and image publishing.
